The problem

Hundreds of pings a day, and wording sets the urgency. Loud beats important.

14:05 · Layla, CEO
“URGENT!!! Can we make the investor deck background blue instead of grey???”
Held until 16:00 cosmetic, can wait
14:20 · Rami, engineer
“hey, is checkout supposed to show 0 JOD for some users? 🤔”
Interrupted you pricing bug before the demo

The idea

  1. Jev answers small judgments with calibrated probabilities: needs_sanad, time_sensitive, wording_only_urgency, blocks_release, family_matter, is_noise.
  2. Code turns them into an action with a truth table you can read, test and tweak.
  3. The LLM only writes: auto-replies, CI explanations, the evening digest.

Privacy and limits

  • Personal sources (Gmail, Calendar) are opt-in; nothing leaves the laptop except the model calls.
  • All people and data are fictional. One day, 34 hand-labelled events, 8 held out: a small set.
  • Labels and rules were corrected after the first real run; every change is logged in data/CHANGELOG.md.
  • The LLM baseline answers the same questions in one prompt at default reasoning; a better prompt might do better.

What's next

  • Learn from “ask” answers: Sanad's clicks become labels and tune the sure band
